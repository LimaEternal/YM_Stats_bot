# YM Stats Bot

Небольшой телеграм-бот, который при запуске опрашивает [API Яндекс Плюса](https://api.plus.yandex.ru/), проверяет вашу актуальную статистику прослушивания Яндекс Музыки и отправляет краткое сообщение с полученными данными вам в личные сообщения Telegram.

## Установка бота
1. Установите Python 3.10+
2. Вручную скачайте репозиторий данного проекта или (при наличии установленного git) скопируйте его данной командой:
   ```powershell
   git clone https://github.com/LimaEternal/YM_Stats_bot.git
   ```
3. В папке проекта создайте виртуальное окружение Python:
   ```powershell
   python -m venv venv
   ```
4. Активируйте созданное вами виртуальное окружение:
   ```powershell
   .\venv\Scripts\Activate
   ```
5. Установите необходимые библиотеки и модули:
   ```powershell
   pip install -r requirements.txt
   ```
6. Создайте файл `.env` в папке проекта и укажите там следующие данные:
   ```env
   TOKEN_YANDEX=<OAuth-токен сервисов Яндекса¹>
   BOT_TOKEN_TG=<токен Telegram-бота²>
   USER_TG_ID=
   ```
   > Поле `USER_TG_ID` оставьте пустым — бот заполнит его сам при первом запуске.

> 1 — можно узнать [здесь](https://yandex-music.readthedocs.io/en/main/token.html)
>
> 2 — выдается в специальном тг-боте [BotFather](https://telegram.me/BotFather)

## Первичная настройка и привязка к Telegram
**Этот шаг нужно выполнить только один раз**, чтобы бот запомнил вас.

1. Убедитесь, что виртуальное окружение активировано (`.\venv\Scripts\Activate`).
2. Запустите бота в режиме регистрации:
   ```powershell
   python bot_start.py long
   ```
3. Найдите своего бота в Telegram и нажмите кнопку **СТАРТ** (или отправьте команду `/start`).
4. Бот ответит, что ваш ID сохранен, и сразу пришлет текущую статистику (если она доступна).
5. Теперь бота можно остановить в консоли (нажмите `Ctrl+C`). Ваш ID автоматически записан в файл `.env`.

## Ежедневный запуск
Теперь, когда бот настроен, используйте скрипт автоматического запуска. Он сам активирует окружение, проверит статистику, отправит отчет и выключится.

**Способ 1 (Рекомендуемый):** Просто запустите файл:
```powershell
.\autorun.bat
```
*Этот файл удобно добавить в Планировщик задач для ежедневной проверки.*

### Дополнительные способы запуска

**Способ 2.1:** Вручную через Python с автоматическим завершением работы (требует активного venv):
```powershell
python bot_start.py
```

**Способ 2.2:** Режим постоянной работы (Long Polling):
```powershell
python bot_start.py long
```
*В этом режиме бот не выключается сам, а ждет команд. Используйте этот режим, если хотите вручную запросить статистику командой /start или сменить основного пользователя (бот перезапишет ID в настройках на ID того, кто последний отправил команду /start)*
