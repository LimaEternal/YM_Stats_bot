##  YM Stats Bot

Небольшой телеграм-бот, который при запуске опрашивает API Яндекс Плюса, проверяет свежую статистику прослушивания Яндекс Музыки и отправляет краткое сообщение в TG только если появились новые данные.

### Установка бота
- Установите Python 3.10+.
- Создайте и активируйте виртуальное окружение:
  ```powershell
  python -m venv venv
  
  .\venv\Scripts\Activate
  ```
- Установите необходимые библиотеки и модули:
  ```powershell
  pip install -r requirements.txt
  ```
  
Создайте файл `.env` в корне проекта и укажите:
```
TOKEN_YANDEX=<OAuth-токен сервисов Яндекса¹>
BOT_TOKEN_TG=<токен Telegram-бота²>
USER_TG_ID=<ваш USER-ID в Telegram, его можно узнать, прописав в боте команду /start>
```
1 - проще всего его можно получить [здесь](https://yandex-music.readthedocs.io/en/main/token.html)  
2 - можно получить у [Bot-Father](https://telegram.me/BotFather)
    
### Запуск бота
1 способ: Через скрипт (автоматически активирует venv, запускает бота и завершает работу после отправки сообщения со статистикой):
  ```powershell
  .\autorun.bat
  ```
2 способ: Напрямую через Python (при активированном venv):
  ```powershell
  python bot_start.py long
  ```
- Параметр long не позволяет боту выключиться автоматически, чтобы вы успели прописать команду /start
