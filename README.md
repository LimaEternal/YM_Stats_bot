##  YM Stats Bot

Небольшой телеграм-бот, который при запуске опрашивает API Яндекс Плюса, проверяет свежую статистику прослушивания Яндекс Музыки и отправляет краткое сообщение в TG только если появились новые данные.

### Установка бота
- Установите Python 3.10+.
- Установите необходимые библиотеки и модули:
  ```powershell
  pip install -r requirements.txt
  ```
  
Создайте файл `.env` в корне проекта и укажите:
```
TOKEN_YANDEX=<OAuth-токен сервисов Яндекса¹>
BOT_TOKEN_TG=<токен Telegram-бота²>
USER_TG_ID=<ваш USER-ID в Telegram, его можно узнать, прописав в боте команду /start³>
```
1 - проще всего его можно получить [здесь](https://yandex-music.readthedocs.io/en/main/token.html)  
2 - можно получить у [Bot-Father](https://telegram.me/BotFather)
3 - возможно только при ручном запуске бота с помощью способа 2.2, расписанного ниже
### Запуск бота
Способ 1: Через скрипт (автоматически активирует venv, запускает бота и завершает работу после отправки сообщения со статистикой):
  ```powershell
  .\autorun.bat
  ```
Для следущих способов необходимо создать и активировать виртуальное окружение, последовательно выполнив следущие команды в папке проекта:
  ```powershell
  python -m venv venv
  
  .\venv\Scripts\Activate
  ```

Способ 2.1: Напрямую через Python - отправка сообщения и автоматическое завершение работы:
  ```powershell
  python bot_start.py
  ```

Способ 2.2: Напрямую через Python - без автоматического завершения работы:
  ```powershell
  python bot_start.py long
  ```
- Необязательный параметр long не позволяет боту выключиться автоматически, чтобы вы успели прописать команду /start

### Как это работает
- Программа сначала проверяет наличие новых данных через [API](https://api.plus.yandex.ru/). Если изменений нет, бот не запускается.
- При получении новых данных пользователю приходит сообщение с итогами прослушивания музыки (количество треков, количество минут/часов) за вчера и накопленными данными за месяц.
