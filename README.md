## Stats Bot

Небольшой телеграм-бот, который раз в запуск опрашивает API Яндекс Плюса, проверяет свежую статистику прослушиваний и отправляет краткое сообщение в TG только если появились новые данные (последние значения отличаются от предыдущих сохранённых).

### Установка бота
- Установите Python 3.10+.
- Создайте и активируйте виртуальное окружение (Windows PowerShell):
  ```powershell
  python -m venv venv
  
  .\venv\Scripts\Activate
  ```
- Установите необходимые библиотеки и модули:
  ```powershell
  pip install -r requirements.txt
  ```
  
Создайте файл `.env` в корне проекта и укажите:
```
TOKEN_YANDEX=<OAuth-токен сервисов Яндекса¹>
BOT_TOKEN_TG=<токен Telegram-бота²>
USER_TG_ID=<ваш USER-ID в Telegram, его можно узнать, прописав в боте команду /start>
```
1 - проще всего его можно получить [здесь](https://yandex-music.readthedocs.io/en/main/token.html)/n
2 - можно получить у [Bot-Father](https://telegram.me/BotFather)
    
### Запуск бота
1 способ: Через скрипт (автоматически активирует venv, запускает бота и завершает работу после отправки сообщения со статистикой):
  ```powershell
  .\autorun.bat
  ```
2 способ: Напрямую через Python (при активированном venv):
  ```powershell
  python bot_start.py long
  ```
- Параметр long не позволяет боту выключиться автоматически, чтобы вы успели прописать команду /start

### Как это работает
- Программа сначала проверяет наличие новых данных через [API](https://api.plus.yandex.ru/). Если изменений нет, бот не запускается.
- При получении новых данных пользователю приходит сообщение с итогами прослушивания музыки (количество треков, количество минут/часов) за вчера и накопленными данными за месяц.
