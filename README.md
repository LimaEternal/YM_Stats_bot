## Stats Bot

Небольшой телеграм-бот, который раз в запуск опрашивает API Яндекс Плюса, проверяет свежую статистику прослушиваний и отправляет краткое сообщение в TG только если появились новые данные (последние значения отличаются от предыдущих сохранённых).

### Подготовка окружения
- Установите Python 3.10+.
- Создайте и активируйте виртуальное окружение (Windows PowerShell):
  ```powershell
  python -m venv venv
  .\venv\Scripts\Activate
  ```
- Установите необходимые библиотеки и модули:
  ```powershell
  pip install -r requirements.txt
  ```

### Переменные окружения
Создайте файл `.env` в корне проекта и укажите:
```
TOKEN_YANDEX=<OAuth-токен сервисов Яндекса, проще всего его можно получить [здесь](https://yandex-music.readthedocs.io/en/main/token.html)>
BOT_TOKEN_TG=<токен Telegram-бота, можно получить у [Bot-Father](https://telegram.me/BotFather)>
USER_TG_ID=<ваш USER-ID в Telegram, его можно узнать, прописав в боте команду **/start**>
```

### Запуск
- Через автоматический скрипт (автоматически активирует venv, запускает бота и завершает работу после отправки сообщения со статистикой):
  ```powershell
  .\autorun.bat
  ```
- Напрямую через Python (при активированном venv):
  ```powershell
  python bot_start.py long
  ```
- Параметр long не позволяет боту выключиться автоматически, чтобы вы успели прописать команду /start

### Как это работает
- `bot_start.py` сначала проверяет наличие новых данных через https://api.plus.yandex.ru/; если изменений нет, бот не запускается.
- При получении новых данных пользователю уходит сообщение с итогами прослушивания музыки (количество треков, количество минут/часов) за вчера и накопленными данными за месяц.
